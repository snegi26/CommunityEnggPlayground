# Information Security Policy

## 1. Identity

All Google Workspace users must enroll in two-step verification.

## 2. Infrastructure

AWS CloudTrail is enabled across all accounts in every region.

Public access to S3 is blocked at the account level in all production accounts.

## 3. Code

The GitHub organization enforces two-factor authentication.
